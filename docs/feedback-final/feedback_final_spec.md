## 1. 데이터

### 1-1. 테이블과 필드

기존 테이블 `lesson_feedbacks`(회차 1건), `lesson_feedback_items`(회차 × 단계 1행)를 쓴다. 7adbe58의 v2 마이그레이션(`20261125120000_lesson_feedback_v2.sql`)으로 생긴 컬럼을 그대로 쓰고, 뜻과 검증만 이 문서대로 바꾼다.

`lesson_feedbacks`

| 컬럼 | 화면 이름 | 타입 | 발행 시 | 손님에게 |
| --- | --- | --- | --- | --- |
| `day_summary` | 그날 종합 피드백 > 오늘 전체 피드백 | text NULL | **필수**, 3000자 이하 | 보임(날짜별 보기, 펼친 채) |
| `next_focus` | 다음에 배울 것 | text NULL (한 줄 input 아님, 여러 줄) | **필수**, 3000자 이하 | 보임(주황 안내 칸의 글) |
| `instructor_note` | 강사 의견 | text NULL | **필수**, 3000자 이하 | 보임(날짜별 보기) |

> `day_summary`는 '다음에 배울 것'·'강사 의견'을 대신하지 않는다. 세 칸은 따로 저장한다(v2 B안 확정). 손님 화면의 다음 단계 안내 글은 `day_summary`가 아니라 **`next_focus`**에서 가져온다.

`lesson_feedback_items`

| 컬럼 | 뜻 | 규칙 |
| --- | --- | --- |
| `mark` | `'o'`/`'triangle'`/`'x'`/NULL | NULL = 오늘 표시 안 함 |
| `step_comment` | 단계 코멘트 | `mark`가 있으면 발행 시 **필수**, 3000자 이하. **표시를 지워도(mark=NULL) 저장된 글은 지우지 않는다**(2-5). 손님 API는 `mark`가 NULL인 행의 코멘트를 **보내지 않는다** |
| `is_next_step` | 다음에 배울 단계 체크 | boolean, 한 회차에 **여러 행 true 가능(개수 제한 없음)**. `mark`가 있는 행도 true 가능(= 보강 단계) |
| `kind_snapshot` | `'step'`/`'milestone'` | milestone(구간 마크 줄)은 표시·코멘트·체크 없음 |

추가 컬럼은 없다. 자동 이동 출처(누가 체크했는지)는 **저장하지 않고** 화면 상태로만 둔다(2-4 참고).

### 1-2. 글자 수

- 네 종류 글 칸(단계 코멘트, 오늘 전체 피드백, 다음에 배울 것, 강사 의견) 모두 **최대 3000자**. 입력칸 `maxLength=3000` + 서버 검증 3000.
- **글자 수 카운터는 보이지 않는다**(`0/500` 같은 표시 없음). 넘으면 서버 오류 문구만: 「OO은 3000자까지 쓸 수 있어요.」
- 앞뒤 공백만 있으면 빈 칸으로 본다(trim).

## 2. 강사 화면 (admin `/cal/feedback/write`)

### 2-1. 순서 (PC 1280, 휴대폰 390 모두 한 줄 세로 흐름)

1. 머리: 「피드백 작성」, 강습생(성 뺀 이름), 강습일, 회차.
2. **맨 위 '다음에 배울 단계' 칸**(주황 옅은 바탕): 지금 체크된 단계를 칩으로 모두 보여 준다. 칩마다 이유 꼬리표(2-4). 아래에 한두 줄 안내문.
3. 종목 토글(스키/보드, 알약).
4. 지난 회차 보기(접힘, 펼치면 지난 회차 표시·코멘트 읽기만).
5. 단계별 평가: 「오늘 한 단계에 ○ △ ✕를 누르면 코멘트 칸이 열려요. 표시한 단계는 코멘트가 필수예요.」
   - 단계 줄: 이름, 그 아래 작은 회색 글 '지난 회차 ○ 할 수 있어요' 또는 '아직 배우지 않음', 오른쪽 ○△✕ 토글.
   - 표시하면: 「{단계} 코멘트 (필수)」 칸이 열린다.
   - 줄 아래 도구: [다음에 배울 단계] 체크 칩(왼쪽), [표시 지우기] 글자 버튼(오른쪽, 표시가 있을 때만).
   - 체크된 단계 줄은 주황 옅은 바탕(`step--next`).
   - 구간 마크 줄(레벨1, 티칭1 취득 도전 등)은 파란 글자(`#3646f0`) 구분선.
6. 등급·뱃지 패널: 지금 구현 그대로.
7. **그날 종합 피드백 칸(맨 끝, PC도 휴대폰도)**: 오늘 전체 피드백(필수) → 다음에 배울 것(필수, 도움말 「손님 화면의 주황색 다음 단계 안내에 이 글이 나가요.」) → 강사 의견(필수).
8. 아래 고정 바: [임시저장](테두리만) [발행](채움 `#1254CF`).

> v2 구현의 오른쪽 옆 칸(aside)과 `mobileSummaryPosition` 설정은 없앤다. 종합 칸은 언제나 맨 끝이다.

### 2-2. 입력칸

- 모든 글 칸은 `<textarea>`, 폭 100%, `min-height: 44px`(오늘 전체 피드백은 더 큰 기본 높이 `input--long`).
- 자동으로 늘어남: CSS `field-sizing: content`, 지원 안 하는 브라우저는 입력 때마다 `height = scrollHeight`로 맞추는 작은 스크립트. 스크롤바가 생기면 안 된다(글이 잘리면 불합격).
- 라벨은 늘 칸 위에 보인다(placeholder로 라벨을 대신하지 않음). 필수 칸 라벨 끝에 「(필수)」, `aria-required="true"`.
- 카운터 없음(1-2).

### 2-3. 필수 입력과 오류

- 검증은 **발행할 때만**. 임시저장은 빈 칸이어도 저장한다.
- 발행 막는 경우: ① 표시한 단계의 코멘트가 빔 ② 오늘 전체 피드백 빔 ③ 다음에 배울 것 빔 ④ 강사 의견 빔 ⑤ 3000자 초과.
- 오류 모습: 맨 위 빨간 알림 「발행하지 못했어요.」 + 첫 문제 칸으로 가는 링크(예: 「스노우플라우 코멘트를 적고 다시 발행해 주세요.」), 해당 칸 빨간 테두리 + `aria-invalid="true"` + 칸 아래 빨간 도움말(「코멘트가 비어 있어요. 오늘 이 단계에서 본 것을 한 줄이라도 적어 주세요.」). 서버도 같은 규칙으로 막는다.
- '다음에 배울 단계' 체크가 하나도 없어도 발행은 된다(필수 아님). 단, 다음에 배울 것 글은 필수.

### 2-4. 다음에 배울 단계: 미리 체크 · 자동 이동 · 복귀 · 보강

용어: **마지막 표시 단계** = 같은 강습생·같은 종목의 **지난 발행 회차들** 전체에서 `mark`가 있는(○△✕ 아무거나, ✕ 포함) 단계 중 순서가 가장 뒤인 단계. 구간 마크 줄은 세지 않는다.

1. **미리 체크** (새 피드백을 처음 열 때, 임시저장본이 없을 때만)
   - 마지막 표시 단계의 **바로 다음 단계**를 `is_next_step=true`로 미리 체크한다. 꼬리표 「(미리 체크됨)」, 단계 줄에 「미리 체크됨: 지난 회차까지 표시가 있는 마지막 단계({이름}) 바로 다음이에요.」
   - 맨 위 칸 안내: 「지난 회차까지 표시가 있는 마지막 단계({이름}) 바로 다음이라 미리 체크했어요. 여러 단계를 함께 체크할 수 있고, 오늘 표시한 단계도 보강할 단계로 체크할 수 있어요.」
   - 마지막 표시 단계가 마지막 단계(스키 '자율활강', 보드 마지막 단계)면 미리 체크 없이 **모든 단계 완료**(5번).
   - 지난 회차가 없으면 미리 체크하지 않는다(맨 위 칸: 「체크한 단계가 없어요. 아래 목록에서 골라 주세요.」).
   - 임시저장본을 다시 열면 저장된 `is_next_step` 그대로 보여 준다(다시 계산하지 않음).
2. **자동 이동**: 체크된 단계(미리 체크든 강사가 직접 체크했든 똑같이)에 **오늘 처음 표시**(표시 없음 → ○/△/✕)를 하면
   - 그 단계 체크를 끄고, **바로 다음 단계**(구간 마크 줄 건너뜀)를 체크한다. 꼬리표 「(자동으로 옮겨짐)」, 옮겨간 단계 줄에 「{단계}에 표시해서 다음 단계 체크가 여기로 옮겨졌어요.」, 맨 위 안내 「{단계}에 오늘 표시를 해서 체크가 다음 단계인 {다음} 단계로 자동으로 옮겨졌어요. 오늘 표시한 단계도 보강할 단계로 다시 체크할 수 있어요.」
   - 다음 단계가 이미 체크돼 있으면 그대로 둔다(옮긴 것으로 기록하지 않음).
   - 다음 단계가 없으면(마지막 단계에 표시) 체크만 끄고 **모든 단계 완료**.
   - 이미 표시가 있던 단계의 ○△✕를 바꾸는 것은 '처음 표시'가 아니므로 옮기지 않는다.
3. **보강**: 오늘 표시한 단계도 [다음에 배울 단계]를 다시 체크할 수 있다. 자동 이동 뒤 지금 단계를 다시 체크하면 **두 단계 모두 체크**된 상태가 된다. 꼬리표 「(오늘 표시한 단계, 보강)」.
   - 보강으로 다시 체크한 뒤 ○△✕를 바꿔도 **체크는 그대로**(옮기지 않음).
4. **복귀** (표시 지우기, 2-5와 함께): 오늘 처음 표시해서 체크를 옮겼던 단계의 표시를 지우면
   - 그 단계 체크를 **다시 켜고**(꼬리표 「(다시 돌아옴)」, 줄에 「표시를 지워서 다음 단계 체크가 이 단계로 돌아왔어요.」), 옮겨간 단계의 체크는 **자동으로 옮겨온 체크일 때만** 끈다(강사가 그사이 그 단계를 직접 끄거나 켰으면 손대지 않음).
   - 마지막 단계에서 '모든 단계 완료'가 됐던 경우 표시를 지우면 체크가 그 단계로 돌아오고 '모든 단계 완료'는 처음 열 때 상태로 돌아간다.
   - 이동 기록은 화면 상태(메모리)에만 둔다. 새로고침이나 임시저장 뒤 다시 열면 복귀는 하지 않고 저장된 체크 그대로 둔다.
5. **모든 단계 완료**: 다음 단계가 없을 때(지난 회차 또는 오늘 마지막 단계까지 표시됨) 맨 위 칸에 초록 큰 글자 「모든 단계 완료」 + 「자율활강까지 표시가 있어서 미리 체크할 다음 단계가 없어요. 보강할 단계는 아래 목록에서 직접 체크할 수 있어요.」
   - 이 상태에서 강사가 보강 단계를 체크하면 **「모든 단계 완료」 문구를 남긴 채** 그 단계 칩을 옆에 함께 보여 준다.
6. 맨 위 칸 칩을 끄면 그 단계 체크가 꺼진다(아래 목록과 같은 상태). 칩 순서 = 단계 순서.
7. 체크 개수 제한 없음.

꼬리표 우선순위(한 칩에 하나): 오늘 표시함(보강) > 다시 돌아옴 > 자동으로 옮겨짐 > 미리 체크됨 > 없음(강사 직접 체크).

### 2-5. 표시 지우기

- 표시가 있는 단계에만 [표시 지우기] 글자 버튼이 보인다. 누르면 `mark=NULL`.
- **코멘트 칸은 숨기고, 쓴 코멘트는 지우지 않는다**(화면 상태와 저장값 모두 유지). 다시 표시하면 그 글이 그대로 다시 보인다.
- 표시가 없는 단계의 코멘트는 발행 검증 대상이 아니고 손님에게 보내지 않는다.
- 체크 복귀는 2-4의 4번.
- 확인 창 없음.

### 2-6. 지난 회차

- [지난 회차 n개 보기](접힘): 같은 강습생·같은 종목의 발행 회차를 최신순으로, 단계 표시와 코멘트를 읽기만.
- 단계 줄의 '지난 회차 ○ 할 수 있어요'는 **직전 회차 값**(그 단계가 처음이면 '아직 배우지 않음').

## 3. 손님 화면 (rideordie `/feedback/...`, 홈페이지 레포)

### 3-1. 구성

1. 머리: 「{성 뺀 이름} {종목} 기록」, 최근 강습일, 기록 n회.
2. **요약**: 큰 숫자 「n」 + 「{전체}단계 중 할 수 있는 단계」(최신 표시가 ○인 단계 수), 단계 수만큼 칸 막대(○ 초록, △·✕ 파랑 `#465fff`, 다음 단계 주황, 안 배운 단계 회색), **주황 '다음에 배울 단계' 칸**, 범례(○ 할 수 있어요 / △ 연습 중 / ✕ 아직 어려워요 / 주황 = 다음에 배울 단계 / 회색 = 아직 배우지 않은 단계).
3. 보기 토글(알약): [단계별] [날짜별].
4. 하단 기존 버튼(예약, 카톡 상담) 그대로.

### 3-2. 주황 '다음에 배울 단계' 칸

- 출처: **가장 최근 발행 회차**의 `is_next_step=true` 단계들(여러 개면 단계 순서대로 모두).
- 단계 이름을 굵게, 보강 단계(그 회차에 `mark`도 있는 단계)는 이름 옆에 주황 배지 **「조금 더 다듬기」**.
- 그 아래 글 = 그 회차의 **`next_focus`(다음에 배울 것)**. 비어 있으면(옛 데이터) **단계 이름만** 보인다.
- 체크된 단계가 없으면 칸을 보이지 않는다(`next_focus` 글만 있으면 날짜별 보기에서만 보임).

### 3-3. 단계별 보기

- 단계 순서대로, 구간 마크 줄 포함.
- **배운 단계**(어느 회차든 표시 있음): 이름 + 최신 표시 배지. 아래에 그 단계의 회차 기록을 **최신이 위로 모두**: 날짜, 「n회차」, 표시, 변화 꼬리표(직전 회차와 다르면 「△ → ○」, 첫 기록이면 「첫 평가」), [강사 코멘트] 열기·접기(**처음엔 접힘**).
- **보강 단계**(최근 회차에 표시 + 다음 단계 체크): 주황 옅은 바탕 + 오른쪽 「조금 더 다듬기」 배지, 기록은 그대로 보인다.
- **다음 단계**(체크됐고 표시 기록 없음): 주황 옅은 바탕 + 「다음에 배울 단계」 + 다음에 배울 것 글(있으면).
- **안 배운 단계**(표시 기록 없음, 체크 없음): 회색 바탕(Neutral200) + 「배우기 전」.

### 3-4. 날짜별 보기

- **지난 회차를 모두** 최신이 위로 보여 준다(시즌 접기 없음). 회차 카드: 「n회차」, 날짜, 「담당 강사」(강사 이름 비노출, 지금 정책 유지).
- **그날 종합 피드백**(`day_summary`): 옅은 파랑 바탕(`#eef1ff`), 제목 파란 글자(`#3646f0`), **늘 펼친 채**.
- 다음에 배울 것(`next_focus`, 있으면), 강사 의견(`instructor_note`).
- 이날 배운 단계: 단계 이름 + 변화 꼬리표 + 표시 배지, 각 [강사 코멘트] 열기·접기(**처음엔 접힘**).

## 6. 수락 기준 체크리스트

강사 화면
- [ ] PC 1280·휴대폰 390 모두 순서: 맨 위 다음 단계 칸 → 종목 → 지난 회차 → 단계 → 등급·뱃지 → 종합 칸(맨 끝) → 고정 버튼.
- [ ] ○△✕를 누르기 전엔 코멘트 칸이 없고, 누르면 열린다.
- [ ] 글 칸 네 종류 모두 3000자에서 더 안 써지고, 카운터가 어디에도 없다. 서버도 3001자를 거절.
- [ ] 10줄 넘는 글을 붙여 넣으면 칸이 늘어나고 스크롤바·잘림이 없다(Chrome, Safari iOS).
- [ ] 발행 시 빈 표시 코멘트 / 빈 오늘 전체 피드백 / 빈 다음에 배울 것 / 빈 강사 의견 각각 오류(맨 위 알림 + 칸 빨간 테두리 + aria-invalid). 임시저장은 통과.
- [ ] 지난 회차 마지막 표시가 ✕인 스템턴이면 패러렐이 「(미리 체크됨)」으로 열린다.
- [ ] 패러렐에 △ → 체크가 베이직 숏턴으로 옮겨지고 「(자동으로 옮겨짐)」.
- [ ] 이어서 패러렐을 다시 체크 → 맨 위 칸에 패러렐(보강)·베이직 숏턴 두 개. 패러렐 표시를 ○로 바꿔도 둘 다 그대로.
- [ ] 강사가 직접 체크한 단계에 처음 표시해도 체크가 다음으로 옮겨진다.
- [ ] 패러렐 [표시 지우기] → 코멘트 칸 숨김, 체크가 패러렐로 돌아오고 베이직 숏턴 체크는 꺼짐. 다시 △ 누르면 아까 쓴 코멘트가 보인다. 임시저장 후에도 코멘트가 DB에 남아 있다.
- [ ] 지난 회차 자율활강까지 표시 → 맨 위 「모든 단계 완료」. 보강 단계를 체크하면 문구와 칩이 함께 보인다.
- [ ] 체크 3개 이상 동시에 가능, 저장·다시 열기 후 그대로.
- [ ] 스키 단계가 13개이고 3번이 스템턴, 레벨1 마크가 베이직 숏턴 뒤, 레벨2 마크가 게이트 뒤.
